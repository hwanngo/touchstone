# Security Policy

## Reporting a vulnerability

**Do not open a public issue for security reports.** Email **security@<your-domain>** (or use
GitHub's *Report a vulnerability* / private security advisory) with steps to reproduce and impact.

We aim to acknowledge within **2 business days** and to provide a remediation timeline based on
severity:

| Severity | Target fix |
|---|---|
| Critical / KEV-listed | 48 hours |
| High | 7 days |
| Medium | 30 days |
| Low | 90 days |

Please give us a reasonable disclosure window before going public. We credit reporters unless you
prefer to remain anonymous.

## Supported versions

| Version | Supported |
|---|---|
| latest | ✅ |
| older | ❌ |
